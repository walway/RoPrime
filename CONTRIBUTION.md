✍️ To contribute to RoPrime you can donate, translate strings or open a pull request

To start contrubuting by editing the code, follow this step-by-step guide
- [**Fork** this project](https://github.com/walway/RoPrime/fork)
- Open it with VS Code or any other editor
- Edit or add the lines <br>
- Use these commands to commit to your repository - <br>
`git add .` <br>
`git commit` <br>
- Do pull request

This project follows the [all-contributors](https://github.com/all-contributors/all-contributors) specification. Contributions of any kind welcome! <br>
Visit their website to learn about [**contribution emoji keys**](https://allcontributors.org/docs/en/emoji-key)
